   corrected at review stage: `docs/ARCHITECTURE.md:85` must describe the **live** trigger (the

   gone, **and** must state (same honesty standard as #9/#10/#12) that no shipped path writes
   `rerank_validation` rows any more.
   → **doc fix only, no code change** (see #5).
2. **#6 — the SQLite `pii_audit_trail` TABLE is canonical.** The legacy `pii_audit.json` must stop
   being the product path: it is already confined to the legacy `strip_and_persist` /
   `ReviewCommand` path (only caller), so the plan **documents the confinement** rather than
   deleting a spec'd (003 FR-018) public writer. **AND** an audit row is recorded for a document with
   **no PII** (today `persist_pii_result` early-returns).
3. **#9, #10, #12 — document, do NOT change behaviour.** Verify `docs/ARCHITECTURE.md` first; it is
   already honest (lines 46 / 69 / 48) → **no-op**.
4. **#11 — delete** the dead `respect_clause_boundaries` field.
5. **#14 — fix** env overrides on the config-creation path.
6. **#16 — fix** the leading-operator drop: an operator with no left operand becomes an ordinary
   term (never silently dropped/rebound).
7. **#17 — read** `retrieval.default_method` / `retrieval.top_k` / `retrieval.rerank_depth` as the
   CLI flag defaults, the same way `rerank_enabled` now is.
8. **#18a — delete** `Reranker.validate()` (no production caller). **#18b — fix** the rerank-row
   label to derive from the actual method.

def delete_pii_data(db_path: Path, document_hash_prefix: str) -> dict[str, bool | int]:
    if len(document_hash_prefix) < 8:
        raise ValueError("document_hash_prefix must be at least 8 characters")
    conn = _get_conn(db_path)
    try:
        rows = conn.execute(
            "SELECT document_hash, mapping_path, review_result_path FROM pii_cache WHERE document_hash LIKE ?",
            (f"{document_hash_prefix}%",),
        ).fetchall()
        for row in rows:
            for path_key in ("mapping_path", "review_result_path"):
                p = Path(row[path_key])
                if p.exists():
                    p.unlink()
        cache_deleted = conn.execute(
            "DELETE FROM pii_cache WHERE document_hash LIKE ?",
            (f"{document_hash_prefix}%",),
        ).rowcount
        audit_count = conn.execute(
            "DELETE FROM pii_audit_trail WHERE document_hash LIKE ?",
            (f"{document_hash_prefix}%",),

        conn.commit()
