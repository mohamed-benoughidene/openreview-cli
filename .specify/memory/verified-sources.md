## ITEM: MAUD (Merger Agreement Understanding Dataset)
- SOURCE: https://www.atticusprojectai.org/maud
- VERSION: v1 (EMNLP 2023)
- KEY FACTS:

  - License: CC BY 4.0

  - Paper: https://arxiv.org/html/2301.00876
- STATUS: CONFIRMED

## ITEM: ContractNLI
- SOURCE: https://stanfordnlp.github.io/contract-nli/
- VERSION: 2021 (Findings of EMNLP 2021)
- KEY FACTS:
  - Document-level natural language inference on NDAs
  - ~600 examples across 3 classes (entailment, contradiction, neutral)
  - Task: classify hypothesis-contract pairs + identify evidence spans
  - Repository: https://github.com/stanfordnlp/contract-nli
  - Baseline model: Span NLI BERT
  - Primary metric: classification accuracy / macro F1
  - Paper: Koreeda & Manning, "ContractNLI: A Dataset for Document-level Natural Language Inference for Contracts"
- STATUS: CONFIRMED
